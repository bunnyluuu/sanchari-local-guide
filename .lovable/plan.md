# SANCHARI Mobile Prototype

## Build
- Create one polished mobile app shell with a short branded entry, role selection, and persistent prototype navigation.
- Implement all 18 requested states as focused screens, linked through the primary traveller and Sancharakudu flows.
- Center the demo on the Secunderabad interview journey, including AI request extraction, a 94% verified match, status progression, completion, review, and AI analysis.
- Add an explicit no-companion branch with actionable transport, navigation, translation, and nearby-service guidance.
- Include prototype safety actions, assistance history, availability controls, incoming request actions, and verified profiles.

## Visual Direction
- Follow the selected Playful Wayfinding direction: paper background, ink typography, coral action color, teal AI layer, blue route cues, mustard match signals, and green live status.
- Use Anton for bold transit-style headings, Inter for interface text, and JetBrains Mono for status labels.
- Keep one dominant action per screen, compact mobile composition, restrained motion, and clear progress markers.

## Interaction
- Make every primary action advance the story without requiring setup.
- Add a compact demo navigator so judges can jump to any screen and switch roles.
- Use timed AI processing and waiting states, while keeping skip/continue controls available.
- Keep all data simulated in-browser; no payments, identity verification, or production backend.

## Validation
- Check the full traveller path, AI fallback branch, and Sancharakudu path on a mobile viewport.
- Verify text fit, tap targets, navigation, and final preview health.
